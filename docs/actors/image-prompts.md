# Character Image Prompts

All 25 pre-generated characters. 25 pre-generated character portrait prompts.

## How to Use

### Midjourney
Paste the full prompt into Discord. Portrait prompts include `--ar 2:3`.

For visual consistency across all characters, run the first character, note the seed (`--seed XXXXXXXX`), and append it to subsequent generations. Or use a style reference with `--sref`.

### DALL-E / ChatGPT
Use the prompt as written — DALL-E handles natural language well. Omit the `--ar` and `--v` flags.

### Stable Diffusion
Add your preferred model's style trigger words. Base prompts work with SDXL + realistic fantasy LoRAs.

## Global Style Reference

Every portrait uses this base style. It is written into each prompt below.

> *painterly digital illustration, Eberron D&D fantasy steampunk setting, neutral dark gradient background, soft dramatic portrait lighting with warm key light from above, 3/4 angle view, detailed face and costume, cinematic depth of field, dramatic but not dark, rich color palette*

## File Naming Convention

| Type | Path | Format |
| --- | --- | --- |
| Portrait | `/assets/images/[slug].png` | 800×1200 px, PNG |

Save at web quality (PNG optimized, or JPG at 85%). Print resolution is not needed.
