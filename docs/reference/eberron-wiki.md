## Linking convention

In `docs/` files, link lore terms on first mention, e.g. `[Zilargo](https://eberron.fandom.com/wiki/Zilargo)`. Fandom blocks some automated fetches (HTTP 403), so open pages in a browser if a tool can't read them.
